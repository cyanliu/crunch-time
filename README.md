# crunch-time

A sandbox for me to experiment with D3.js + React (and maybe other dataviz/motion graphics libraries? 🤞), with the idea that it would eventually become a website I can use to track and visualize my fitness accomplishments over time.

## Running locally

Clone the repository, and run

```
npm run dev
```

to create a local instance of the web application hosted at `localhost:3000`.
